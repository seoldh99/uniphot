# Contributing to uniphot

## Issues are welcome

Please use GitHub issues for bug reports, questions and suggestions. For a bug, please include:

- the output of `uniphot --version` and `uniphot doctor`;
- how you installed uniphot (conda or pip) and your GPU model;
- your configuration file, `RUN_STATUS.json` and the end of `run.log` from the work folder;
- if you can, a small input that shows the problem.

Do not attach data that you are not allowed to share. This includes the 7DT sample data, whose license
does not allow redistribution.

## Pull requests are not accepted at this time

Please do not send pull requests or other code contributions for now, while the license of future versions
is being decided. Open an issue instead.
